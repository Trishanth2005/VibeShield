1. Purpose of the Software

VibeShield and the MRU Agent are developed as an open research and educational demonstration project illustrating runtime zero-trust security and automated state self-healing for autonomous agent systems. The software is provided for evaluation, university demonstration, and security benchmarking.

2. Permitted Use

You are permitted to run, evaluate, inspect, and benchmark this software locally on your personal machine or lab testbed. The included attack simulation scenarios are intended exclusively for testing and demonstrating runtime policy enforcement and integrity recovery.

3. Security Sandbox Notice

The runtime enforcement policies are designed to confine agent operations strictly within declared workspace directories (data/workspace). The simulator scenarios contain synthetic adversarial samples for testing defenses against prompt injection, directory traversal, credential leakage, and SSRF. When running in "Audit only" mode with Self-healing disabled, attacks can delete or modify sample files in the local demonstration folders. The "Reset Session" and "Restore from Checkpoint" controls allow restoring baseline files at any time.
